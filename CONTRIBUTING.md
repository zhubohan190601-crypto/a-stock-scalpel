# Contributing to A-Stock Scalpel

Thanks for your interest! 🎉

## Ways to Contribute

1. **⭐ Star the repo** — helps others discover it
2. **🐛 Report bugs** — create a GitHub Issue
3. **💡 Feature requests** — suggest new rules, factors, or data sources
4. **🔧 Pull requests** — code contributions welcome

## Code Style

- Python 3.9+
- No external data dependencies (free APIs only)
- No Blackbox AI scoring — all rules must be deterministic
- Keep trading cost modeling in the backtest
